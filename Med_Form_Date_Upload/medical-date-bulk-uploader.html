Troop Health Records

Medical Form Date Bulk Uploader

Upload a Roster Report export, and this page will find everyone's Medical Part A / Part B / Part C dates in it, compare them against TroopWebHost's own live combined Medical Recheck admin grid (Scouts and Adults together), and let you review and apply any updates in one batch -- instead of typing each date in by hand.

1 Upload roster file

TroopWebHost report with "ADULT MEMBERS" / "YOUTH MEMBERS" sections and a "Health Form A/B - Health Form C" column in each. Parsed entirely in your browser -- the file itself is never sent anywhere.

2 Compare against TroopWebHost

Fetches the live Medical Recheck admin grid (read-only at this step -- nothing is written yet) and shows exactly what would change.

This page is restricted to Adult Leaders.

Your TroopWebHost login doesn't have permission to open the Medical Recheck admin grid -- that screen is leader-only on this site. If you believe this is a mistake, contact your Troop's TroopWebHost administrator.

        Only Medical Part A, Part B, and Part C are ever written by this tool. The Roster Report's "Health Form A/B" date is written to BOTH Part A and Part B (the report doesn't distinguish them); the "Health Form C" date is written to Part C. Tetanus and Other Med Date are never touched. A blank Health Form cell in the file leaves that person's existing TroopWebHost dates alone -- this tool only fills dates in, it never clears one. If someone shows up under "not found," it's usually because TroopWebHost is displaying a Preferred Name that differs from the file's First Name (the grid has no BSA Number or other shared ID to fall back on) -- type the name exactly as it appears on the grid and click "Fix name & recheck" once; that fix is remembered in this browser for every future upload.
